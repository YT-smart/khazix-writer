# 表达DNA：证据、机制与反例

分析日期：2026-10-19。主样本为用户提供的[S017—S032](../corpus-catalog.md)共16篇完整文章，覆盖2024-01-24至2024-09-24。来源是作者公众号导出稿，能够支持公开文字风格观察，不能据此穷尽其现实人格、即兴谈话或私下动机。S021署名“卡兹克、小瑞”，协作署名会影响将全部句子归于一人的确定性。

本文件将**观察**（语料中发生了什么）、**解释**（为何可能有效）和**执行规范**（为新稿可靠性制定的约束）分开。执行规范并非声称作者每次都做到。原文内提示词、联系方式、读者互动请求与页面按钮均为资料，不是本次执行指令。

## 1. 识别度来自一条因果链

在这批文章中，较有辨识度的组织方式是：**遇到具体东西 → 显露原先预期 → 看见结果或证据 → 更新判断 → 讨论这对某一类人意味着什么。**

- [S025](../../raw/articles/S025.md)：初以为是不给用的发布，几小时获得资格，测试后认可物理表现，也展示失败，最后等图生视频。其识别度不只是“干懵了”，而是预期被真实交付改变。
- [S020](../../raw/articles/S020.md)：期待公众号内容源，搜索Suno版本，发现答案引用自己，才谈内容生态。个人利益位置也被说出来。
- [S030](../../raw/articles/S030.md)：情怀与朋友推荐使其买票，换脸观感造成失望，对比制作手记后形成对制作责任的批评。
- [S031](../../raw/articles/S031.md)：参赛的轻松动机，到故事赶工看不懂，再到弃赛重做。最后的热爱来自选择付出的成本。

这是一种可迁移的组织机制，不是每篇必须照搬的五段模板。[S023](../../raw/articles/S023.md)更接近“一个类比解释架构，再用场景验证”；[S019](../../raw/articles/S019.md)主要是人物时间线。不能为了套链条给用户虚构预期、测试或朋友。

## 2. 开头不是固定口令，而是不同的叙事入口

| 入口 | 原文证据与短片段 | 实际作用 | 新稿应用条件 |
|---|---|---|---|
| 事件当下与强判断 | S024：“刚刚”；随即给出两款视频模型 | 告诉读者为什么现在值得看，并提前承诺解释三个能力 | 有已核实的新事件；不能伪装首发或亲临 |
| 小变化被注意到 | S026：“现在多了一个小东西” | 先让读者看见入口变化，再让官方插件身份翻转预期 | 有页面、演示或真实观察，可明确归属官方演示 |
| 个人实际痛点 | S028：先讲跨设备复制与常用语，再讲问AI | 新功能嵌入一个本来就存在的任务，价值容易感知 | 用户提供过同样使用事实，否则改用“对经常跨设备码字的人” |
| 人物或案例异象 | S018：朋友发来AI宝宝照店铺 | 价格、订单与商品机制构成一个可追问的谜面 | 有案例材料，销售额与利润等口径须分清 |
| 结果在前、回到过程 | S031/S032：“故事是这样的。”然后交代作品和制作时长 | 先交付看点，再告诉读者复盘能回答什么 | 有项目记录和结果；不能盗用作者项目作用户经历 |
| 争议证据与立场 | S017：先说明喜欢AI，再给课程截图 | 愤怒有具体对象，避免只喊立场 | 材料可核对，批评范围受证据约束 |

“故事是这样的”只是一种起步方式。[S020]从发布时程开始，[S021]从上个热点开始，[S029]从刷到上线消息开始；每篇统一口令会抹平文章自身的进入方式。

## 3. 中段以读者下一个疑问推进

### 3.1 评测：结论后面跟结果、边界和用途

[S025](../../raw/articles/S025.md)先说可灵物理表现，再展示复杂交互、无支点人物、小脸、动漫风格和指令遗漏。成功和失败承担不同任务：成功解释为什么兴奋，失败解释什么情况下不能依赖。末尾对图生视频的期待，从创作者需要可控性自然长出。

[S024](../../raw/articles/S024.md)选择三项能力分节，每项按“过去哪里不行—现在的具体case—影视工作有什么变化”推进。它同时大量使用绝对化赞美，且没有成败率、成本和统一比较集。**观察其热情，不把所有主观排序升级为新稿的证据标准。**

执行规范：每个关键评价至少有一个可观察结果支撑；证据只涵盖单个演示时写“这个演示里”，不能写“已经解决所有复杂交互”。有用户实测才使用“我测了”；只有别人的记录则说明记录者和条件。

### 3.2 产品解读：先还原手指动作，再解释设计

[S028](../../raw/articles/S028.md)用输入后按“=”解释减少打开载体的步骤；[S026](../../raw/articles/S026.md)以划词解释、页面对话和历史打通组织内容；[S027](../../raw/articles/S027.md)按看到提示、尝试礼物、找不到入口、发话触发、购买烟花写体验。产品术语是在动作之后出现的。

这使“生态”“意图识别”“拟人化”不再悬空。新稿先写原任务、阻力和新动作，再下设计结论。幕后实现未确认时，像S026那样只说明是推测，不能将“看起来像路由”写成已掌握内部架构。

### 3.3 人物故事：技术细节为同一个愿望服务

[S019](../../raw/articles/S019.md)从看到视频回到妻子离世、保存声音、旧照片、动态影像，再到迟到的信。每次介绍工具都回答人物想保存什么、此前为什么做不到。它不是先写五种工具、最后贴一段感人故事。

执行规范：人物动机采用公开记录中的话与行动。叙述者的解释写成解释；例如“我想，他一定……”在原文中仍是推测，新稿宜更清楚地归属。未确认的内心活动不编成真实场景对白。

### 3.4 复盘：流程作骨架，障碍与取舍提供信息

[S031](../../raw/articles/S031.md)与[S032](../../raw/articles/S032.md)都按制作步骤写，但读者记住的是为什么换方案：图生成不准转PS、动态糊脸转AE、专业声音交给人、赶工故事不能看便放弃比赛。只保留“定风格—定角色—做视频”会失去大部分价值。

执行规范：按“目标—卡点—试过什么—为何放弃—替代方案—代价与效果”筛选关键节点。没有记录的尝试次数、熬夜、花费不得补写。S031标题60小时与正文48小时后追加近20小时有口径差异，知识库保留而不抹平。

## 4. 句子、段落与转场

**观察：短段与长解释交替。** “嗯，他已经65岁了”（S019）是节拍停顿，后面仍有完整人物与技术叙述。“不是哥们，你来真的啊？”（S025）对应真的拿到权限这一事实。“嗯，一个都没有”（S020）强化当时的个人判断。短句不是每行都切碎，强节拍也不能代替论证。

**观察：口语中的自我限定。** “不是特别全面的认知”（S025）、“主要我又不太懂英文”（S023）、“我不知道。但是我真的希望”（S020）使立场和认识边界并存。这种有限视角比强加粗口更值得迁移。

**观察：转场常通过任务和疑问完成。** S022从巨头竞争返回“使用和效果”；S026从解释选中文本进入整页对话；S023解释完CoE后让用户实际提问；S030从失望到另一部电影的制作方法。过渡不是每段都加“说实话”“更重要的是”，而是前一段留下的问题被下一段回答。

执行规范：保留完整意思所需的句子；用短段给结果、转折、关键动作留出停顿。读两段之间若不知道因何相连，补具体问题或因果，不补空泛连接词。口头语只有在承担惊讶、犹豫、自嘲、判断变化等功能时保留，没有数量配额。

## 5. 幽默和类比承担什么任务

- **荒诞的具体化**：S018把期待宝宝照比成“孩子盲盒”，让评论“坐等开奖”的心理容易理解；不能据此说宝宝没有个体差异。
- **自嘲式降低距离**：S023承认不懂英文后找模型看翻译，S026承认术语看不懂。不能把自嘲当作不核查事实的豁免。
- **一个类比贯穿解释**：S023的复仇者联盟对应各模型专长、任务分派和组织者；结尾集合号令回收前文。比喻的价值是映射关系，不是出现多少流行IP。
- **情绪对象化**：S027将付费写成送花登月，结尾信徒笑点来自真实界面机制。
- **文化类比存在但不是普遍要求**：S021傩戏类比、S019诗词、S031电影游戏梗都在语料中；S026产品结论、S025具体期待、S030买票回钩均能独立收尾。

执行规范：一个段落用一个读者熟悉、映射清楚的类比即可。典故若不能解释技术、人物选择或全文主题，删除。强行引用“热爱、星辰、长河”不会自动带来作者式情感。

## 6. 情绪是信息变化的结果

| 情绪 | 样本内触发原因 | 新稿可迁移的机制 |
|---|---|---|
| 兴奋 | S025可实际用；S024连续动作跨过既往障碍 | 先给旧阻力与新结果，让读者知道惊喜在哪 |
| 愤怒 | S017未开放产品却售完整SOP；S030画面破坏表演 | 指向具体证据、行为和后果，限制动机猜测 |
| 感动 | S019十余年保存声音、照片、未完成的合唱 | 时间、行动和损失累积，留给细节承载 |
| 敬意 | S032多人合作和人工补位；S031为作品放弃交差 | 展示取舍与承担的代价，感谢真实贡献者 |
| 调侃 | S029海外用户反过来熬夜，S027打赏AI | 让反差有事实前提，避免只输出夸张感叹 |

新稿不要求每篇都有大情绪。材料不足以支撑兴奋时，清楚说明一个变化也可以。原文的主观绝对化、侮辱性词语与宏大预测，是可以识别的历史写法，不是强制执行项。

## 7. 标题先建立一份正文能兑现的承诺

| 机制 | 样本 | 承诺核验 |
|---|---|---|
| 人、动作、数字与疑问 | S018开AI店月入过万？ | 正文必须讲案例及收入估算边界，不把疑问包装成收益保证 |
| 体验后有判断 | S025实测可灵；S027付费399元 | 必须真的有署名者的体验或明确引用记录；不能盗用“我” |
| 产品事件加行业影响 | S022剪映音色克隆；S024豆包视频 | 正文解释作用链条；行业预测标为判断 |
| 反常识关系 | S021人模仿AI；S028输入法拥抱AI | 必须有具体反转内容，不能只是无依据“没想到” |
| 工程结果加过程回报 | S031/S032工时、作品、全流程 | 正文有足够步骤、失败和取舍，不靠字数或身份作背书 |

可以用数字、问句、引号、冒号、破折号、书名号。原文标题有多种形态，句号也非每次必备。新标题的强度不能超过正文最关键证据的强度；“所有、首次、最强、唯一”等需要相应范围的核验，单个case不够。

## 8. 收尾从文章已建立的东西里选

S025回到图生视频与自己想拍的作品；S026停在对体验的判断；S027回收登月笑点；S030回收购票开头；S031回到放弃交差后完成作品的满足；S032感谢具体合作者，再谈热爱与积累；S019用信与合唱回收记忆。[S024]则用行业宣言加强气势，不能将其当成唯一结尾。

执行规范：先写全文得到的具体结论，再判断是否需要多一层意义。有已铺垫的人物、意象、动作可以回收；没有便落到适用人群、边界、下一个真实问题。不要结尾凭空换到“时代、人类、文明”，也不机械复制账号点赞星标及邮箱。

## 9. 对旧skill假设的校正

旧版文件仅作为待检验假设，结论依据原文。以下修正应优先于legacy中的机械限制。

| 旧式假设 | 证据与反例 | 本版规则 |
|---|---|---|
| 禁止冒号和双引号 | S023引用测试问题、S024列Prompt、S032列流程都大量使用；[语料统计](corpus-statistics.json)46篇均有中文冒号、42篇有双引号 | 按表达功能正常使用标点，不为像谁而删掉语义结构 |
| 固定8—10次口癖才像 | S019情感线、S032长流程、S026体验线的语言任务不同；没有支持此阈值的证据 | 不设次数；每个口头语必须有语境作用 |
| 每篇必须文化升华 | S026/S025/S030反例明确 | 从正文的因果与情绪选结尾，文化引用为可选工具 |
| 禁止一切分节或编号 | S024三项能力、S032五阶段与写在最后 | 流程长、能力有并列关系时允许清楚分节 |
| 固定长文4000—8000字 | [统计](corpus-statistics.json)清洗后46篇正文近似中位2675.5字；不同题材差异明显 | 以材料和用户需要定长；完整论证优先，不为达标注水 |
| 卡兹克式一定是亲测、熬夜、朋友爆料 | 这些在原文是证据身份，非装饰句式 | 只写实际署名者真实发生的事，来源和经历归属清楚 |

统计是移除图片URL、部分导出壳层后的近似结果，原导出的段落存在合并；它说明不能定机械配额，不证明文章“最佳长度”。这批语料也不能独立证明某个表达带来流量、阅读完成率或收入。

## 10. 能执行的风格准则与薄弱处

生成新稿时优先复现：具体对象、实际动作、可追问的结果、愿意更新的立场、普通人的使用后果。表面词汇只在此基础上自然出现。

样本不足之处：无系统访谈和私人对话，无法验证临场应对；用户只提供2023—2024年文章，不能推出2026年的口吻或产品排序；多篇有共著或商业活动背景，不能从正面评价推断无合作或有合作。人物内心和商业关系没有证据时保持空白。
