# Khazix Writer

卡兹克风格的公众号文章创作 Skill。

这个项目把卡兹克的公开文章、人物判断方式、写作框架、可追溯知识库和公众号 HTML 排版流程整合到了一起，用来学习他的观察方式和内容工作流。

## 它是什么

Khazix Writer 不是简单复制卡兹克的口头禅，也不是让模型冒充卡兹克本人。

它包含三层内容：

- 人物层：从公开文章归纳出的判断模型、价值取舍、表达特征和边界
- 知识层：46 篇有效公众号原文、来源卡、主题页和实体页
- 交付层：公众号正文、配图方案、HTML 排版和 base64 图片处理

知识库中的文章已经移除了公众号阅读器附加的扫码、授权、分析、点赞、分享等无关内容，只保留正文、图片链接、作者署名和文章结尾。

## 它能做什么

- 用卡兹克的观察方式分析一个新主题
- 写 AI 产品体验、行业观察、工具教程和项目复盘
- 把复杂的 AI 概念讲成普通人能理解的事情
- 从知识库检索相关主题和历史文章
- 输出公众号 Markdown 正文和配图方案
- 用户确认正文后，再生成公众号 HTML
- 将本地图片转成 base64 `data:` URI，方便复制到公众号编辑器

## 五个核心判断框架

1. 从用户卡住的地方反推方案
2. 把能力宣传翻译成具体任务，并保留失败边界
3. 按目标、成本和效果选择人机组合
4. 除了能力，还要看入口、工作流和迁移成本
5. 沿着技术动作，追到它改变了谁的生活

这些框架是基于公开文章的分析归纳，不是卡兹克本人发布的官方方法论。

## 怎么用

将整个仓库作为一个 Codex Skill 使用，然后直接提出请求，例如：

> 用 Khazix Writer 写一篇关于 AI 知识库的公众号文章。

或者：

> 按卡兹克的观察方式，分析这个 AI 产品对普通人有什么意义。

Skill 会先理解用户要求，再从知识库检索相关主题、人物框架和原文依据。涉及最新产品、价格、版本或开放资格时，需要另外核对当前资料；旧文章只说明当时的作者判断。

## 分阶段交付

### 第一阶段：正文和配图方案

先生成：

- `article.md`
- `image-plan.md`

这一阶段只确认文章内容、角度、事实边界和配图需求。

### 第二阶段：HTML

用户确认正文后，再生成：

- `article.html`
- `article.preview.html`
- `sources.md`

HTML 会保持和 Markdown 正文一致，不在排版阶段偷偷改写内容。

有图片时，先把图片下载到文章素材目录，核对来源和用途，再转成 base64 `data:` URI 嵌入 HTML。远程图片链接不能直接作为最终公众号图片地址。

## 知识库结构

```text
raw/
├── articles/      # 清洁后的完整原文
├── layout/        # 公众号 HTML 排版样本
└── manifest.json  # 来源、日期、哈希和状态

wiki/
├── sources/       # 每篇文章的来源卡
├── concepts/      # 跨文章主题页
├── entities/      # 人物、产品和模型实体页
├── index.md       # 知识库索引
└── log.md         # 维护日志

references/
├── persona.md     # 人物与判断框架
├── writing.md     # 写作流程和表达规则
└── layout.md      # 微信排版规则
```

## 原文范围

知识库当前包含 46 篇有效公众号文章，署期覆盖 2023-12-29 至 2024-10-04。

这些材料反映的是公开文章中的表达和判断，不能代表卡兹克截至今天的全部观点或近况。涉及最新产品、价格、版本和开放资格时，仍需单独核验。

## 适用边界

这个 Skill 只供学习卡兹克的观察方式、写作框架和内容工作流。

它不能：

- 冒充卡兹克本人
- 把卡兹克的经历改成用户亲历
- 编造购买、测试、采访或现场经历
- 把 2024 年的产品信息直接当成今天的事实
- 用口头禅和标点规则批量生产“卡兹克味”文章

学习一个人的最终目的，应该是形成自己的判断和风格。

## 本地运行排版脚本

```bash
python scripts/render_wechat.py article.json --output-dir output
```

图片使用本地文件或已经准备好的 base64 `data:` URI。远程图片链接不能直接作为最终公众号 HTML 图片地址。

## 目录维护

清理公众号阅读器附加内容：

```bash
python scripts/clean_wechat_chrome.py .
```

检查来源指纹、摘要覆盖和本地链接：

```bash
python scripts/audit_skill.py
```
