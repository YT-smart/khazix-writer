# Khazix Writer

卡兹克风格的公众号文章创作 Skill。

## 它是什么

这个 Skill 把卡兹克的公开文章、人物判断方式、写作框架、知识库和公众号排版经验放到了一起。

它不是简单复制几个口头禅，也不是让 AI 冒充卡兹克本人。

它真正想学习的是：卡兹克遇到一个新工具、新现象或新问题时，会先看什么，怎么验证，怎么判断，最后怎样把复杂的东西讲给普通人听。

知识库里包含 46 篇有效公众号原文，以及人物框架、主题资料和产品资料。原文已经清理掉了微信阅读器附加的扫码、授权、分析、点赞、分享等无关内容。

## 它能做什么

- 用卡兹克的观察方式分析一个新主题
- 写 AI 产品体验、行业观察、工具教程和项目复盘
- 把复杂的 AI 概念讲成普通人能理解的事情
- 从知识库中查找相关主题和历史文章
- 根据用户素材写公众号文章
- 给文章安排合适的配图
- 在正文确认后生成适合复制到公众号的排版内容

## 五个核心判断框架

1. 从用户卡住的地方反推方案
2. 把能力宣传翻译成具体任务，并保留失败边界
3. 按目标、成本和效果选择人机组合
4. 除了能力，还要看入口、工作流和迁移成本
5. 沿着技术动作，追到它改变了谁的生活

这些框架是根据公开文章做出的分析归纳，不是卡兹克本人发布的官方方法论。

## 安装方式

不需要手动复制文件，也不需要自己研究安装路径。

在 Codex、Claude Code 或其他支持 Skill 的 agent 里，直接说：

> 请帮我安装这个 Skill：
> https://github.com/YT-smart/khazix-writer.git

安装完成后，重新打开一个对话，或者让 agent 重新加载 Skill 即可。

以后需要更新时，直接说：

> 请帮我更新 Khazix Writer skill。

## 怎么使用

安装后，直接告诉 agent 你想写什么：

> 用 Khazix Writer 写一篇关于 AI 知识库的公众号文章。

或者：

> 按卡兹克的观察方式，分析这个 AI 产品对普通人有什么意义。

也可以把新闻、产品资料、个人经历、采访记录或已有草稿一起交给它：

> 用卡兹克的公众号写作方式，把下面的产品资料写成一篇文章。我的亲身体验是……

agent 会先理解主题和读者，再查找知识库里的相关资料，选择合适的判断框架，然后组织文章。

## 文章创作流程

默认分两步进行。

第一步，先写正文，同时给出配图建议。你先看文章的主题、角度、事实和节奏，确认内容没问题。

第二步，正文确认以后，再生成公众号排版内容。如果有图片，会先确认图片来源和用途，再转成 base64 图片，避免复制到公众号时因为外链失效而显示空白。

第三步，全选复制到公众号草稿。


## 只供学习

这个 Skill 只供学习卡兹克的观察方式、写作框架和内容工作流。

请保留自己的经历、判断和表达方式，不要把卡兹克的购买、测试、采访或现场经历写成自己的亲历，也不要让文章冒充卡兹克本人发布。

学习一个人的最终目的，是形成自己的风格。
